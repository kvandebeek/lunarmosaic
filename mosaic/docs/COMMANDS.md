## panel_classifier.py

Score panel quality; `--relative` ranks overlapping panels on shared terrain.

Examples:

```sh
python3 panel_classifier.py panels -o panels/panel_manifest.json --relative
```

Full help:

```text
usage: panel_classifier.py [-h] -o OUTPUT [--recursive] [--ext EXT]
                           [--border BORDER] [--erode ERODE] [--tiers TIERS]
                           [--relative] [--radius-tol RADIUS_TOL]
                           [--workers WORKERS] [--log LOG]
                           inputs [inputs ...]

Score the quality of every image in one or more folders and write a JSON manifest + Markdown report.

Single-image metrics work on any image set. With --relative, overlapping images (mosaic panels) are
also compared on shared terrain, which is the authoritative quality ranking. Files are never moved.

    python3 panel_classifier.py <folder|file> [...] -o manifest.json [--relative]

positional arguments:
  inputs                image files and/or folders

options:
  -h, --help            show this help message and exit
  -o, --output OUTPUT   manifest JSON path (report written next to it as .md)
  --recursive           also scan subfolders (default: False)
  --ext EXT             file extensions to include, comma-separated (default:
                        tif,tiff,png,jpg,jpeg)
  --border BORDER       px trimmed from every edge (default: 32)
  --erode ERODE         px removed along a real subject edge (default: 40)
  --tiers TIERS         percentile cut points (default: 10,25,75)
  --relative            also rank overlapping images on shared terrain
                        (default: False)
  --radius-tol RADIUS_TOL
                        px: compare only pixels at about equal distance from
                        both frame centres (default: 200)
  --workers WORKERS     parallel worker threads (default: 8)
  --log LOG             append the console log to this file (default: None)
```

## mosaic_builder.py

Build the mosaic (nine steps), with live preview, movies and a contribution map.

Examples:

```sh
python3 mosaic_builder.py panels -o mosaic.tif
python3 mosaic_builder.py panels -o mosaic.tif --no-preview --record build.mp4 --record-vertical build_9x16.mp4
python3 mosaic_builder.py panels -o mosaic.tif --stop-after 3        # layout only (fast check)
```

Full help:

```text
usage: mosaic_builder.py [-h] -o OUTPUT [--manifest MANIFEST]
                         [--exclude-tier EXCLUDE_TIER]
                         [--proxy-factor PROXY_FACTOR] [--features FEATURES]
                         [--min-keypoints MIN_KEYPOINTS]
                         [--pair-search {index,all}] [--max-points MAX_POINTS]
                         [--stop-after STOP_AFTER]
                         [--model {poly3+mesh,poly3,poly2,affine,similarity}]
                         [--north-up | --no-north-up] [--levels LEVELS]
                         [--border BORDER]
                         [--background {neutral-black,neutral,keep}]
                         [--limb-feather LIMB_FEATHER]
                         [--colour-balance {highlands,disk,none}]
                         [--workers WORKERS] [--preview | --no-preview]
                         [--display-tif | --no-display-tif]
                         [--record MOVIE.mp4] [--record-vertical MOVIE.mp4]
                         [--log LOG] [--log-pairs]
                         inputs [inputs ...]

Build a mosaic from overlapping panels.

Implemented so far (build phase 2): stages 0–3. Preflight, proxies + features, pair discovery and
global similarity alignment, with a live preview and a layout report. Stages 4–8 (fine alignment,
photometry, region selection, blending, background/colour, output) follow in phases 3–4.

    python3 mosaic_builder.py <folder|manifest.json> [...] -o mosaic.tif [--no-preview]

positional arguments:
  inputs                image folders/files and/or panel manifest JSON

options:
  -h, --help            show this help message and exit
  -o, --output OUTPUT   output TIFF path (layout files are written next to it)
  --manifest MANIFEST   optional manifest: exclude rejects, apply --exclude-
                        tier (default: None)
  --exclude-tier EXCLUDE_TIER
                        comma-separated tiers to exclude (default: none)
                        (default: )
  --proxy-factor PROXY_FACTOR
                        proxy downscale factor for pair discovery (default 4 =
                        0.25×) (default: 4)
  --features FEATURES   SIFT keypoints per panel (on the proxy) (default:
                        4000)
  --min-keypoints MIN_KEYPOINTS
                        panels with fewer keypoints are not placed (default:
                        150)
  --pair-search {index,all}
                        index = one feature index over all panels (fast); all
                        = brute force over every pair (default: index)
  --max-points MAX_POINTS
                        correspondences per pair used in the global solve
                        (default: 300)
  --stop-after STOP_AFTER
                        last stage to run, 0–8 as numbered in the log ([0/8]
                        preflight … [8/8] output); the movie numbers the same
                        steps 1–9 (default: 8)
  --model {poly3+mesh,poly3,poly2,affine,similarity}
                        pose model for fine alignment (poly3 = gentle cubic
                        warp per panel; +mesh = plus a smooth 256 px
                        displacement mesh fitted on dense 128 px tiles, ≈ 1
                        min extra; measured best) (default: poly3+mesh)
  --north-up, --no-north-up
                        turn the mosaic itself to lunar north up, east right
                        (never mirrored), inside the blend; by default
                        lunar_finish.py does this as its last step (default:
                        False)
  --levels LEVELS       multi-band pyramid levels (default: 7)
  --border BORDER       px cropped at every frame edge; auto = measured
                        stacking artefact + 3 px (default: auto)
  --background {neutral-black,neutral,keep}
                        neutral-black = neutral sky, then black space; neutral
                        = neutral sky only; keep = unchanged (default:
                        neutral-black)
  --limb-feather LIMB_FEATHER
                        px cosine ramp from the limb to black (default: 12)
  --colour-balance {highlands,disk,none}
                        highlands = neutral grey highlands; disk = neutral
                        whole disk; none = no colour balance (default:
                        highlands)
  --workers WORKERS     parallel worker threads (default: 9)
  --preview, --no-preview
                        live preview window (default: True)
  --display-tif, --no-display-tif
                        also write <out>_display.tif (the mosaic with the
                        movie's tone mapping) (default: True)
  --record MOVIE.mp4    also record what the preview shows to a 16:9 MP4
                        (works without a display) (default: None)
  --record-vertical MOVIE.mp4
                        also record a 9:16 version (1080×1920, e.g. Instagram
                        Reels) (default: None)
  --log LOG             append the console log to this file (default: None)
  --log-pairs           log every accepted pair (default: False)
```

## lunar_finish.py

Phase 2 on the finished mosaic: highlights, lunar colour, gentle contrast; before/after movie.

Examples:

```sh
python3 lunar_finish.py mosaic.tif -o mosaic_finished.tif
python3 lunar_finish.py mosaic.tif -o mosaic_finished.tif --saturation 3 --record finish.mp4
```

Full help:

```text
usage: lunar_finish.py [-h] -o OUTPUT [--highlights HIGHLIGHTS]
                       [--knee-percentile KNEE_PERCENTILE]
                       [--saturation SATURATION]
                       [--saturation-passes SATURATION_PASSES]
                       [--contrast CONTRAST] [--usm AMOUNT,RADIUS,THRESHOLD]
                       [--usm-mode {luminosity,rgb}]
                       [--wavelets BIASES|pixinsight]
                       [--wavelet-kernel {linear,b3}]
                       [--wavelet-denoise K1,K2,…] [--keep-orientation]
                       [--north-up] [--no-wavelets]
                       [--chroma-denoise CHROMA_DENOISE]
                       [--limb-taper LIMB_TAPER] [--date DATE]
                       [--preview | --no-preview]
                       [--display-tif | --no-display-tif] [--record MOVIE.mp4]
                       [--record-vertical MOVIE.mp4]
                       input

Phase 2: finishing touches for a lunar mosaic, with an optional before/after movie.

0. Optional wavelet sharpening (--wavelets), for unsharpened stacks, reproducing PixInsight's ATrousWaveletTransform
   (target RGB/K, no noise reduction or deringing): dyadic layers of 1, 2, 4, 8 px (linear-interpolation or B3-spline
   scaling function) on each channel's stored values, layer k multiplied by PixInsight's gain for its bias:
   1 + 10 · bias, or 1 / (1 + 10 · |bias|) below zero. The biases are PixInsight's own numbers.
   --wavelets pixinsight = 4 layers, linear (3), layer 1 bias +2.3. Optional per-layer noise protection
   (coefficients within DENOISE × the layer's noise keep weight 1).
1. Highlights: brightness is split into a smooth base and fine detail (edge-aware guided filter); a gentle
   shoulder lowers only the brightest part of the base, and the detail goes back unchanged. Bright rays and
   rims come down while keeping their texture.
2. Lunar colour: colour-only noise smoothing (3 px: the same idea as a sharp luminance layer coloured by a blurred
   colour layer in Photoshop), then more saturation along the Moon's natural hues (blue and orange-yellow). Greens, purples and pinks get only a small share of the boost (usually noise or fringing).
   Applied in passes (default 2): each pass multiplies saturation again.
3. Contrast: a gentle S-curve on brightness; black stays 0 and white stays 1.
4. Optional sharpening, reproducing Photoshop's Unsharp Mask: d = original − Gaussian(σ), result = original +
   amount × sign(d) × max(|d| − threshold, 0), threshold in 0–255 levels (Photoshop's threshold is soft: it is
   subtracted, not a cut-off). σ is slightly wider than the radius, as measured in Photoshop 2026: 1.08 × radius at
   1 px, 1.05 × at 2 px, 1.03 × at 4 px. Photoshop sharpens each RGB channel separately in an RGB image; the default
   here sharpens brightness only (like Fade → Luminosity), which avoids colour fringes. --usm-mode rgb gives
   Photoshop's per-channel behaviour.

5. North up (default; --keep-orientation to skip): moon_atlas locates the finished image, which is then turned
   so lunar north is up and east is right (never mirrored), in one Lanczos resample, and cropped to the Moon.

All adjustments work on brightness or colour separately (CIE Lab), so they do not shift each other.
The input is never modified. Measured on the 2026-09-25 mosaic: colourful pixels lie 46 % in blue
(240–300°), 30 % in orange–yellow (60–120°), 0.9 % in green, ~7 % in purple/pink.

    python3 lunar_finish.py mosaic.tif -o mosaic_finished.tif [--usm 100,1.5,0] [--record finish.mp4] [--record-vertical f.mp4]

positional arguments:
  input                 16-bit RGB TIFF (e.g. mosaic.tif from
                        mosaic_builder.py)

options:
  -h, --help            show this help message and exit
  -o, --output OUTPUT   output TIFF (16-bit, uncompressed); the input is never
                        changed
  --highlights HIGHLIGHTS
                        0 = off; fraction by which the knee-to-top span is
                        lowered (< 0.5) (default: 0.3)
  --knee-percentile KNEE_PERCENTILE
                        highlight roll-off starts at this brightness
                        percentile of the disk (default: 90.0)
  --saturation SATURATION
                        saturation factor on the lunar hues (1 = off)
                        (default: 2.0)
  --saturation-passes SATURATION_PASSES
                        how many times the saturation boost is applied
                        (default: 2)
  --contrast CONTRAST   midtone contrast increase (0.12 = +12 %), 0 to < 0.5
                        (default: 0.12)
  --usm AMOUNT,RADIUS,THRESHOLD
                        sharpen like Photoshop's Unsharp Mask, e.g. 100,1.5,0
                        or "100;1,5;0" (amount %, radius px, threshold in
                        0–255 levels, all as Photoshop shows them); off by
                        default (default: None)
  --usm-mode {luminosity,rgb}
                        luminosity = brightness only (no colour fringes); rgb
                        = every channel, as Photoshop does in RGB mode
                        (default: luminosity)
  --wavelets BIASES|pixinsight
                        wavelet sharpening first, as PixInsight's
                        ATrousWaveletTransform: comma-separated layer biases
                        in PixInsight's own units (gain 1 + 10 × bias), e.g.
                        0.6,1.1,0.2,0; 'pixinsight' = 4 layers, linear (3),
                        layer 1 +2.3; off by default (default: pixinsight)
  --wavelet-kernel {linear,b3}
                        scaling function: linear = PixInsight 'Linear
                        Interpolation (3)', b3 = 'B3 Spline (5)' (default:
                        linear)
  --wavelet-denoise K1,K2,…
                        per layer: coefficients within K × the layer's noise
                        level keep weight 1 (0 = off, the default) (default:
                        None)
  --keep-orientation    keep the orientation as captured (default: last step
                        turns the image to lunar north up, east right)
                        (default: True)
  --north-up            turn north up even if .env says
                        LUNAR_FINISH_NORTH_UP=0 (default: True)
  --no-wavelets         skip the wavelet step even if .env sets
                        LUNAR_FINISH_WAVELETS (default: False)
  --chroma-denoise CHROMA_DENOISE
                        px (Gaussian σ): colour-only smoothing before the
                        saturation boost; brightness keeps all detail. Like a
                        luminance layer coloured by a blurred colour layer in
                        Photoshop (Color blend mode) (default: 3.0)
  --limb-taper LIMB_TAPER
                        px: no extra saturation at the limb, full boost this
                        far inside (default: 80.0)
  --date DATE           caption for the movie (default: taken from the input's
                        folder) (default: None)
  --preview, --no-preview
                        live preview window (default: True)
  --display-tif, --no-display-tif
                        also write <out>_display.tif (the result with the
                        movie's tone mapping) (default: True)
  --record MOVIE.mp4    record the before/after movie, 16:9 (1920×1080)
                        (default: None)
  --record-vertical MOVIE.mp4
                        the same movie in 9:16 (1080×1920), e.g. Instagram
                        Reels (default: None)
```

## tools/compare_crops.py

Same-terrain 100 % crops of two panels, or a blind test with a sealed key.

Examples:

```sh
python3 tools/compare_crops.py panels/panel_manifest.json --pair 2103_9,2109_2 -o compare.png
python3 tools/compare_crops.py panels/panel_manifest.json --blind 6 -o blind/
```

Full help:

```text
usage: compare_crops.py [-h] (--pair PAIR | --blind N) [-o OUT] [--size SIZE]
                        [--seed SEED]
                        manifest

Same-terrain 100 % crops of overlapping panels, to check quality scores by eye.

Crops come from the overlap interior at about equal distance from both frame centres (so the measured
centre-to-edge falloff cancels), both stretched identically.

    python3 compare_crops.py panel_manifest.json --pair 2103_9,2109_2 [-o out.png]
    python3 compare_crops.py panel_manifest.json --blind 6 [-o blind_dir]

--blind N picks N pairs (4 with a large score difference, the rest near-equal), randomises left/right,
labels them X/Y only, and writes the answer key to key.json. Judge first, then open the key.

positional arguments:
  manifest

options:
  -h, --help     show this help message and exit
  --pair PAIR    two panel ids, comma-separated (default: None)
  --blind N      blind test with N pairs (default: None)
  -o, --out OUT  output PNG (with --pair) or folder (with --blind) (default:
                 .)
  --size SIZE    crop size in px (100 %) (default: 400)
  --seed SEED    random seed for the blind selection and left/right order
                 (default: 7)
```

## tools/edge_falloff.py

Detail versus distance from the frame edge (optics / tilt diagnostic).

Examples:

```sh
python3 tools/edge_falloff.py panels/panel_manifest.json --by side
```

Full help:

```text
usage: edge_falloff.py [-h] [--pairs PAIRS] [--by {distance,side}]
                       [--seed SEED]
                       manifest

How does image detail change towards the frame edge? (optics / tilt / stacking diagnostic)

For overlapping panel pairs from a panel manifest (panel_classifier.py --relative), each panel's detail is
compared with its partner's on the same terrain, using only partner pixels deep inside the partner frame.
Results are relative to the panel's own interior, so terrain and panel quality cancel out.

    python3 edge_falloff.py panel_manifest.json [--pairs 200] [--by distance|side]

--by distance : detail vs distance from the nearest frame edge
--by side     : detail within 32–300 px of the left / right / top / bottom edge (asymmetry hints at tilt)

positional arguments:
  manifest

options:
  -h, --help            show this help message and exit
  --pairs PAIRS         number of overlapping pairs to sample (default: 200)
  --by {distance,side}  distance = by distance from the nearest frame edge;
                        side = per frame edge (tilt check) (default: distance)
  --seed SEED           random seed for the pair sample (default: 1)
```

## design_mockups/render_mockups.py

Render the preview-window design options from a real layout.

Examples:

```sh
python3 design_mockups/render_mockups.py --layout mosaic_layout.json --view natural
```

Full help:

```text
usage: render_mockups.py [-h] [--layout LAYOUT] [--out OUT]
                         [--stage1-panel STAGE1_PANEL]
                         [--stage2-pair STAGE2_PAIR]
                         [--view {natural,machine}]

Render preview-window design mockups (3 styles × 3 stages) from real data.

Reads the panels listed in a layout JSON written by mosaic_builder.py (stage 3) and renders
A (Mission Control), B (Observatory) and C (Blueprint) for stages 1, 2 and 3, plus a contact sheet each.

    python3 render_mockups.py --layout mosaic_layout.json [--out DIR]

options:
  -h, --help            show this help message and exit
  --layout LAYOUT       layout JSON written by mosaic_builder.py (default:
                        mosaic_layout.json)
  --out OUT             output folder (default:
                        /Volumes/Astro/LunarMosaic/mosaic/design_mockups)
  --stage1-panel STAGE1_PANEL
                        panel id shown in the feature mockup (default: 2103_9)
  --stage2-pair STAGE2_PAIR
                        two panel ids shown in the matching mockup (default:
                        2117_0,2117_6)
  --view {natural,machine}
                        natural: gentle global tone curve on linear luminance
                        (what you would see); machine: the contrast-enhanced
                        proxy the feature detector works on (default: natural)
```
